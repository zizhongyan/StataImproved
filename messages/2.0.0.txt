-------------------------------------
Stata Improved Editor 2.0.0
-------------------------------------

Now for Sublime Text 4 on macOS and Windows.

* Runs on Sublime Text 4's current Python plugin host (Python 3.14).
* NEW: Windows support, no setup needed: code is typed into Stata's
  Command window (Stata may be minimized or busy). If no Stata is
  running, the newest installed Stata is started.
  Windows keys: Ctrl+D / Ctrl+Enter do, Ctrl+R run, Ctrl+Shift+D block,
  Ctrl+K Ctrl+S break line, F1 help, F2 browse, Ctrl+/ comment.
* All key bindings now only apply in Stata files, so Ctrl+D, Cmd+Enter
  etc. keep working in R, Python, ... files (#30).
* "$" only wraps a selection; typing "$" alone inserts "$" again (#21, #25, #27).
* Cmd+/ (Ctrl+/) without a selection comments the line with // (#28, #32).
* macOS: pin the Stata version with "stata_version" in the settings (#34).
* macOS: Cmd+` is left to the system; use Ctrl+Alt+` for `word'. Ctrl+Alt+B
  opens the Data Browser (F2 clashes with Sublime's bookmarks) (#24, #29).
* Macros `x' and $x / ${x} have their own color scope (#9).
* New settings: "cd_to_file_directory" (#20), "send_whole_lines" (#25),
  "local_macros_persist" (#3), "custom_commands" (#35, command palette:
  "Stata Improved: Highlight Additional Commands").
* Fixed: errors on one-letter words (#37) and unsaved files (#38);
  temporary do-files are created inside the temp directory, one per run (#39);
  the last block after the final break line can be executed.

Settings: Preferences > Package Settings > Stata Improved Editor.

Project homepage: https://github.com/zizhongyan/StataImproved
